# NBC scenario instructions

NBC is reference evidence only (ADR 0032). This directory holds provenance
(`source-manifest.v1.json`) for the NBC scenario catalog; it is not a source
of runtime behavior and Bunting does not aim for NBC compatibility.

Do not add NBC-mode scenarios. A Bunting scenario inspired by an NBC case is a
normal Bunting scenario under `scenarios/` with Bunting semantics, citing this
provenance only as background.
