# Competitor examples

The dependency-free Python client performs the required FIXT.1.1 Logon against
the local practice roster. The maintained QuickFIX-Go example and external
interoperability gate lives in `tests/interop/quickfixgo`; it exercises the same
profile using an independent production FIX implementation.

Clone normally—do not use `--recursive`. Reference repositories under `ref/`
are evidence inputs and are never required to build, practise, or compete.
